# Rengginang Situbondo Putra JAYA - Sumenep

Implementasi web landing page & sistem katalog e-commerce instan untuk UMKM **Putra JAYA (Rengginang Situbondo - Sumenep, Madura)** menggunakan **React.js + Tailwind CSS + Vite**.

Dibuat sesuai dengan tampilan desain referensi secara presisi (pixel-perfect) dilengkapi dengan fitur interaktif lengkap.

---

## ✨ Fitur-Fitur Utama

1. **Header & Navigasi**:
   - Logo UMKM **PJ - Putra JAYA** (Rengginang Situbondo - Sumenep).
   - Menu navigasi pill: *Beranda* & *Katalog Produk*.
   - Icon keranjang belanja dengan badge dinamis (default `3` item seperti pada desain).
   - Tombol **Login Pengelola** dengan avatar user.

2. **Hero Section**:
   - Badge keunggulan: *Belanja tanpa akun* (hijau) & *UMKM Sumenep Madura* (peach).
   - Headline utama: *"Rengginang gurih, khas Putra JAYA."*
   - Tombol CTA: *"Lihat 4 Varian Rengginang →"* & *"Tentang UMKM"*.
   - Poin kepercayaan: *Tanpa unduh aplikasi*, *Checkout instan 1-menit*, *Beras ketan mutu premium*.
   - Kartu visual unggulan dengan foto asli 4 bungkus rengginang, badge *PENJEMURAN ALAMI - 100% Sinar Matahari Madura*, serta indikator *Empat varian rasa - Rp28.000 /bks*.

3. **Cerita UMKM (Value Proposition)**:
   - 3 Kartu keunggulan:
     - 🍲 **Produk Tradisional** (*Higienis & Gurih ✓*)
     - 📋 **Informasi Jelas** (*Stok Terpantau Realtime 🔄*)
     - 🚚 **Pemesanan Praktis** (*Dukungan Ekspedisi Aman 🛡️*)

4. **Katalog 4 Varian Rengginang Pilihan**:
   - **Rengginang Terasi** (Badge `TERLARIS`, Rp28.000/bks, Sisa 24 bks)
   - **Rengginang Udang** (Badge `FAVORIT`, Rp28.000/bks, Sisa 16 bks)
   - **Rengginang Bawang** (Badge `KLASIK`, Rp28.000/bks, Sisa 27 bks)
   - **Rengginang Cumi** (Badge `SPESIAL`, Rp28.000/bks, ⚠️ Sisa 3 bks)
   - Tombol *"Pesan Sekarang"* yang langsung memasukkan ke keranjang belanja.
   - Tombol *"Buka Katalog Lengkap & Tips Menggoreng →"*.

5. **Belanja Tanpa Repot (Call to Action)**:
   - Headline *"Cukup pilih, isi data, konfirmasi"*.
   - Tombol *"Mulai Pesan →"* & *"Tanya via WhatsApp"*.
   - Baris metrik: *100% Beras Ketan Asli*, *4 Varian Rasa Tradisional*, *Rp28.000 Harga Terstandar*, *Madura Sentra Sumenep*.

6. **Footer Lengkap**:
   - Info legalitas UMKM Binaan Resmi.
   - Menu Belanja Praktis.
   - Kontak & Sentra Produksi (Desa Marengan, Kec. Kota Sumenep, Madura).
   - Akses Pengelola: Tombol *"Login Owner Mas Ifur 🔒"*.

7. **Fitur Interaktif Tambahan**:
   - 🛒 **Cart Drawer**: Mengubah jumlah item, hapus item, kalkulator berat paket, dan subtotal.
   - 📝 **Modal Checkout Cepat (Tanpa Akun)**: Form nama, WhatsApp, alamat, pilihan ekspedisi (J&T / SiCepat / JNE / Indah Logistik), dan tombol direct WhatsApp dengan template pesan otomatis.
   - 🔐 **Portal Owner Mas Ifur**: Monitoring cuaca penjemuran matahari Sumenep (33°C) dan manajemen stok harian secara realtime.
   - 🍳 **Modal Tips Menggoreng**: 4 langkah menggoreng agar rengginang mekar maksimal & meletup renyah.

## 🚀 Cara Menjalankan Project

Di terminal direktori `c:\Rengginang_Putra_Jaya`:

```bash
# Menjalankan server pengembangan lokal (Vite)
npm run dev
```

Buka URL yang ditampilkan di terminal (biasanya `http://localhost:5173`) di browser Anda.

Untuk build versi produksi:
```bash
npm run build
```
Hasil build siap upload akan tersimpan di folder `dist/`.
